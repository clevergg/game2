# Ассеты и лицензии

Все ассеты игры **сгенерированы кодом этого репозитория**. Сторонних изображений, моделей, шрифтов, звуков и музыки в игре нет.

| Ассет | Как получен | Команда |
|---|---|---|
| `atlas.png` — Бухгалтерия (10 рангов × 4 анимации, стол, пол, стена) и общее: дебик, кредик, кукиш, записка, конверт, колба, слоповина, иконки, портреты Тоси Боси и Кудесницы Алеси, пиксельный шрифт | процедурные low-poly модели (`scripts/assets/page/models`), рендер в headless Chromium, палитра и дизеринг (`scripts/assets/lib`) | `bun run assets` |
| `atlas-1.png` — Склад, `atlas-2.png` — Конторка дизайнеров (по 10 рангов × 4 анимации, стол, пол, стена); `atlas.json` — общая таблица кадров всех листов | то же | `bun run assets` |
| Звуковые эффекты (15 шт.) | синтез WebAudio по рецептам `src/engine/audio/sfx.ts`, рендерится в игре при старте | прослушать: `bun run audio:preview` |
| Музыка (луп 8 тактов) | секвенсор `src/engine/audio/music.ts`, рендерится в игре при старте | прослушать: `bun run audio:preview` |
| Пиксельный шрифт 5×7 | глифы заданы в `scripts/assets/lib/font.ts` | `bun run assets` |

## Инструменты генерации (в игру не входят)

| Инструмент | Лицензия | Роль |
|---|---|---|
| [three.js](https://github.com/mrdoob/three.js) | MIT | построение и рендер 3D-моделей при генерации атласа |
| [Playwright](https://github.com/microsoft/playwright) | Apache-2.0 | запуск headless Chromium для рендера |

## Интеллектуальная собственность

Игра использует общий словарь интернет-мема «Конторка» (батраканы, кукиши, отдел квадров и т.д.), который распространился через ремиксы многих авторов. Визуальный дизайн персонажей, модели, анимации, звук и тексты — собственные. Имена «Тося Бося» и «Кудесница Алеся» используются по решению заказчика (риск принят осознанно, GDD §0.1); их внешность — наш дизайн в стиле батраканов, а не копия персонажей оригинала. Ролики, модели, название и логотип аккаунта ООО «Слоп» не используются.
