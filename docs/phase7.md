# Фаза 7 — интеграция Yandex Games SDK

> Итог Фазы 7 (07.10.2026). Готов архив для загрузки в черновик консоли. Дальше — Фаза 8 (страница игры, тексты, обложки, отправка на модерацию), после «дальше».

## 1. Что сделано

| Блок | Результат |
|---|---|
| `YandexPlatform` (`src/platform/yandex.ts`) | SDK подключается динамически с относительного `/sdk.js`, ожидание `YaGames.init()` — не больше 3 с. Каждый вызов SDK обёрнут: ошибка платформы не роняет игру. |
| Выбор платформы (`src/main.ts`) | На хостинге Яндекса — SDK; если он не загрузился или завис — `LocalPlatform` без рекламы. На localhost/в домашней сети SDK не ищем (имитация рекламы для разработки). Принудительно: `?platform=yandex` / `?platform=local`. |
| Жизненный цикл | `LoadingAPI.ready()` — когда игра готова к вводу; `GameplayAPI.start/stop` — на входе в игру, при сворачивании, на время рекламы (без повторных вызовов). |
| Пауза | Единый менеджер пауз (`src/game/pause.ts`): скрытая вкладка, наша реклама, внешняя пауза `game_api_pause/resume`. Игра и звук идут, только когда нет ни одной причины паузы. |
| Реклама | `showRewardedVideo` — награда только после `onRewarded`; `showFullscreenAdv` — в естественных паузах и под ограничителем `core/ad-guard`. Если SDK не позвал колбэк, через 90 с игра снимает паузу сама. Ошибка показа — честное «Реклама сейчас недоступна», награды нет. |
| Облачные сохранения | Локальная копия пишется всегда, в облако (`player.setData`) — не чаще раза в минуту, принудительно (сворачивание, реорганизация) — не чаще раза в 15 с, отложенная запись не теряется. При загрузке берётся более свежее из локального и облачного (`src/platform/cloud.ts`, с тестами). |
| Время | Дни (поручения, аванс) и отгул считаются по `serverTime()` — перевод часов на устройстве не даёт лишних авансов. |
| Доска почёта | Лидерборд `career`: «Карьера = выслуга × 100 + открытые карточки». Отправка — при росте карьеры, не чаще раза в 30 с и только если метод доступен (`isAvailableMethod`). Вкладка «Почёт» в отделе квадров: топ-10 и игрок рядом; без входа — кнопка «Войти через Яндекс ID» (вход необязателен, играть можно без него). |
| Архив | `bun run pack` → `release/kontorka-1.0.0.zip`: `index.html` в корне, имена латиницей без пробелов, 0,7 МБ без сжатия (лимит 100 МБ), проверка, что в коде нет сторонних доменов и SDK подключается с `/sdk.js`. Свой ZIP-упаковщик — работает на Windows без утилит. |
| Тесты | 127 юнит-тестов (+ облако, ограничитель, пауза, карьера, ZIP и правила архива). Смоук: 18 проверок игры + 18 проверок матрицы отказов с поддельным SDK. |

## 2. Сверка фактов SDK

Сайты `yandex.ru`/`yandex.com` из среды разработки заблокированы, поэтому сверка — по поисковой выдаче документации и по типам `@types/ysdk` 1.2.0 (npm). Расхождений с интеграцией не найдено.

| Факт | Источник |
|---|---|
| `ysdk.adv.showFullscreenAdv({callbacks: {onOpen, onClose(wasShown), onError, onOffline}})`; `showRewardedVideo({callbacks: {onOpen, onRewarded, onClose, onError}})`, награда — в `onRewarded` | [Реклама](https://yandex.com/dev/games/doc/en/sdk/sdk-adv), `@types/ysdk` |
| `game_api_pause` / `game_api_resume` сообщают о рекламе, покупках, смене вкладки и сворачивании; на паузе платформа сама вызывает `GameplayAPI.stop()` | [События](https://yandex.com/dev/games/doc/en/sdk/sdk-events) |
| Лидерборды: новый API `ysdk.leaderboards.setScore/getEntries/getPlayerEntry`, счёт — целое неотрицательное, не больше 60 запросов в минуту, проверка `isAvailableMethod` | [Лидерборды](https://yandex.com/dev/games/doc/en/sdk/sdk-leaderboard) |
| Данные игрока: `player.getData/setData(data, flush)`, `isAuthorized()`; частые запросы ограничены | [Данные игрока](https://yandex.com/dev/games/doc/en/sdk/sdk-player) |
| Архив: ≤ 100 МБ без сжатия, `index.html` в корне, имена без пробелов и кириллицы; SDK обязателен; модерация 3–5 рабочих дней | [Требования](https://yandex.com/dev/games/doc/en/concepts/requirements), [Модерация](https://yandex.com/dev/games/doc/en/concepts/moderation) |
| `serverTime()`, `environment.i18n.lang`, `auth.openAuthDialog()` | `@types/ysdk` |

## 3. Матрица отказов

| Что сломалось | Поведение игры | Чем проверено |
|---|---|---|
| `/sdk.js` не загрузился (404, офлайн) | мгновенный старт на `LocalPlatform`, реклама «недоступна», сохранение локальное | `bun run smoke` |
| `YaGames.init()` завис | старт через 3 с на `LocalPlatform` | `smoke:sdk` — hang |
| Реклама: ошибка / нет заполнения / исключение | сообщение «Реклама сейчас недоступна», награды нет, игра не на паузе | `smoke:sdk` — broken |
| SDK не вызвал колбэк рекламы | через 90 с пауза снимается | код (`AD_SAFETY_MS`) |
| `getPlayer` упал | только локальные сохранения | `smoke:sdk` — broken |
| Облако недоступно / лимит запросов | запись в облако пропускается, локальная копия есть; при следующем старте берётся более свежая | тесты `cloud.test.ts` |
| Лидерборд недоступен / нет входа | вкладка «Почёт» объясняет и предлагает вход; игра не ждёт лидерборд | `smoke:sdk` — ok/broken |
| Внешняя пауза во время рекламы и свёрнутой вкладки | игра продолжится, только когда сняты все причины | тест `Pauser`, `smoke:sdk` — ok |
| Перевод часов устройства | дни по `serverTime()`, отрицательное отсутствие = 0 | тесты `days` |

## 4. Что сделать в консоли Яндекс Игр (заказчику)

1. Собрать архив: `bun run pack` → `release/kontorka-1.0.0.zip` (или взять из сообщения в чате).
2. [Консоль разработчика](https://games.yandex.ru/console) → «Добавить приложение» → название «Конторка: Батраканы», языки **русский и английский**.
3. «Черновик» → загрузить архив.
4. **Лидерборды** → создать с техническим названием **`career`** (именно так — это имя в коде), название «Доска почёта» / «Hall of Fame», числовой тип, сортировка по убыванию, отметить как основной. `[verify]` — точные названия полей в консоли.
5. Открыть черновик по ссылке из консоли (у Яндекса есть отладочная панель) и пройти чек-лист ниже на телефоне и на ПК (Chrome, Firefox).
6. Написать, что получилось, — и в Фазе 8 готовим страницу игры (описания ru/en, иконка, обложка, скриншоты) и отправку на модерацию.

**Чек-лист черновика:**

- [ ] Игра загружается, загрузочная полоска исчезает, нет чёрного экрана.
- [ ] Язык: на русском Яндексе — русский, на `yandex.com` — английский.
- [ ] «Премия» и «Калоид» показывают настоящую рекламу; после досмотра бафф включается; во время рекламы нет звука.
- [ ] «Смена отшабашена!» → «Забрать» иногда показывает межстраничную рекламу (не чаще раза в 2 минуты).
- [ ] Свернуть вкладку — звук пропадает, вернуться — игра продолжается.
- [ ] Закрыть и открыть игру — прогресс на месте; с другого устройства под тем же Яндекс ID — тоже (облако).
- [ ] Вкладка «Почёт» показывает доску после входа.
