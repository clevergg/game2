**Видео** записывается с настоящей сборки детерминированно: часы страницы подменены (Playwright clock), игровое время шагает ровно на кадр, кадры кодирует ffmpeg (`ffmpeg-static`, инструмент разработки). Сценарий 26 с: тапы и всплывающие кукиши → слияния со штампом «ПОВЫШЕНИЕ!» → найм → записка Хозяина → лифт на Склад и в Конторку дизайнеров → Кудесница Алеся в отделе квадров → снова Бухгалтерия. Интерфейс на русском, без звука (каталог показывает превью без звука).

Все картинки сгенерированы кодом из ассетов игры; скриншоты сняты с настоящей сборки (Playwright) на подготовленном сохранении «середины игры» — это реальный геймплей, как требует Яндекс.

Превью в репозитории: `docs/img/promo-icon-512.png`, `docs/img/promo-cover-800x470-ru.png`, `docs/img/promo-cover-800x470-en.png`.

## 3. Тексты страницы игры

### Русский

**Название:** Конторка: Батраканы

**SEO-описание (130):**
Idle-кликер про офис батраканов: колупай циферки, нанимай и сливай сотрудников, поднимайся по этажам Конторки до кабинета Хозяина.

**Описание (786):**

```
Добро пожаловать в Конторку! Здесь работают батраканы — и работают они на тебя.

• Колупай циферки: тапай по батраканам — кукиши посыплются сами.
• Нанимай и сливай: два одинаковых батракана становятся одним рангом выше — от стажёра до приближённого к Хозяину.
• Поднимайся на лифте: Бухгалтерия, Склад и Конторка дизайнеров — у каждого этажа свои батраканы, столы и доход.
• Лови дебиков, открывай записки Хозяина, выполняй план смены и поручения Тоси Боси.
• Реорганизуйся: выслуга навсегда увеличивает доход, а Кудесница Алеся из отдела квадров меняет печати на перки.
• Собери картотеку — 30 рангов и 30 редких премированных батраканов.
• Батраканы колупают, даже когда тебя нет: забирай отгул и ежедневный аванс.

Короткие сессии, управление одним пальцем и абсурдный офисный юмор.
```

**Как играть:**

```
Тапай по батраканам — они колупают циферки и приносят кукиши. Нанимай новых кнопкой внизу. Перетащи батракана на такого же — они сольются в старший ранг; лишнего отправь в слоповину. Открывай новые этажи на лифте, улучшай отделы и реорганизуйся в отделе квадров, чтобы расти быстрее.
```

## 4. Пошаговая публикация

1. `bun run pack` и `bun run promo` (или файлы из чата).
2. [Консоль](https://games.yandex.ru/console) → «Добавить приложение» → название, языки ru/en.
3. Черновик → загрузить `kontorka-1.0.0.zip`.
4. Лидерборды → создать `career` (docs/phase7.md §4).
5. Страница игры → вставить тексты из §3 для обоих языков, загрузить иконку, обложки и скриншоты (mobile и desktop, отдельно для ru и en).
6. Возраст, категории, ориентация — по таблице §3.
7. Открыть черновик и пройти чек-лист §5 на телефоне и на ПК (Chrome, Firefox).
8. «Отправить на модерацию». Ждать 3–5 рабочих дней.
9. Если модерация вернёт замечания — прислать текст замечания в чат: правим, пересобираем `bun run pack`, загружаем заново.

## 6. Риски модерации

- **Название и персонажи.** «Конторка», «Тося Бося» и «Кудесница Алеся» — из мема; решение использовать имена принято заказчиком осознанно (GDD §0.1). Внешность, модели, тексты — собственные. Если модерация сочтёт название чужим брендом — запасное название **«Батраканы: Офисный idle»** / «Workroaches: Office Idle» (в коде меняется одна строка в словарях и обложки через `bun run promo`).
- **Реклама.** Межстраничная — только в паузах и не чаще раза в 2 минуты; частоту дополнительно ограничивает Яндекс.
