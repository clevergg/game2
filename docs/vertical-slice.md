# Фаза 5. Вертикальный срез — «Конторка: Батраканы»

> 29.09.2026. Цель среза — проверить, что **в это весело играть**. Один полный цикл с настоящей графикой, звуком и управлением: запуск → тап → найм → слияние → повышение → новый ранг. Мета-прогрессии, событий и рекламы здесь нет, они появятся в Фазах 6–7.

## 1. Что входит в срез

| Есть | Как работает |
|---|---|
| Старт без меню | сразу офис: один стажёр за столом, подсказка «Колупай циферки!» над его головой |
| Тап по батракану | +кукиши (1 + 15% дохода в секунду), всплывающее «+N», зелёные циферки из-под клавиатуры, сплющивание, щелчок клавиши |
| Пассивный доход | каждый батракан раз в секунду выплачивает свой доход; столы выплачивают вразнобой, числа всплывают над головами |
| Найм | большая кнопка внизу, цена растёт с каждым наймом; при нехватке кукишей или мест — тряска кнопки и зуммер |
| Слияние | перетаскивание батракана на такого же → ранг выше (доход ×3), штамп «ПОВЫШЕНИЕ!», тряска экрана, фонтан кукишей и циферок, анимация радости |
| Новый ранг | тост «Новый ранг: …» и фанфара, 10 рангов |
| Перенос и обмен | на пустой стол — перенос, на батракана другого ранга — обмен местами; цель подсвечивается (золотом, если можно слить) |
| Слоповина | ведро в левом нижнем углу: бросаешь лишнего батракана — стол свободен, часть цены возвращается. Последнего выбросить нельзя, иначе тупик |
| Подсказки первой сессии | «тапай» → «найми ещё одного» (пульсирует кнопка) → «перетащи одного на другого»; каждая исчезает после действия и больше не показывается |
| Звук и музыка | синтез в реальном времени, звук включается с первого касания (так требуют браузеры), кнопка звука вверху справа запоминает выбор |
| Сохранение | в `localStorage`: каждые 15 с, после слияния, при сворачивании и закрытии вкладки |
| Пауза | в свёрнутой вкладке цикл и звук полностью остановлены |
| Языки | ru/en по языку браузера |
| Десктоп | мышь как палец, пробел колупает случайного батракана, игра в центральной колонке |

**Вне среза (Фазы 6–7):** записки Хозяина, шабашки, дебики, премия и калоидный ускоритель, реорганизация, картотека, доска почёта, аванс, отгул, покупка столов 9–12, реклама, Yandex SDK, симулятор баланса. Экономика — стартовые формулы из GDD без подгонки.

## 2. Как запустить

### 2.1. На компьютере (Windows 11)

1. Один раз поставить [Bun](https://bun.sh) — в PowerShell: `powershell -c "irm bun.sh/install.ps1 | iex"`.
2. В папке проекта:
   ```
   bun install
   bun run dev
   ```
3. Открыть `http://localhost:5173` в Chrome или Firefox.
   Чтобы посмотреть мобильную раскладку на компьютере: DevTools (F12) → переключатель устройства (Ctrl+Shift+M) → например, Pixel 7.

Продакшн-сборка, как её увидит Яндекс: `bun run build`, дальше отдать папку `dist/` любым статическим сервером (например, `bunx serve dist`).

### 2.2. На телефоне (та же Wi-Fi сеть)

1. На компьютере `bun run dev`. При первом запуске Windows спросит про брандмауэр — **разрешить для частных сетей**.
2. Узнать IP компьютера: `ipconfig` → «IPv4-адрес» Wi-Fi адаптера, например `192.168.1.23`.
3. На телефоне открыть `http://192.168.1.23:5173`.
4. Если не открывается: телефон и компьютер должны быть в одной сети, а сеть в Windows должна быть «частной», а не «общественной».

### 2.3. Проверки

| Команда | Что проверяет |
|---|---|
| `bun run check` | типы, линт, формат, 73 юнит-теста, сборка, бюджет |
| `bun run smoke` | собирает игру и **играет за игрока** в эмуляции телефона (Playwright): 12 проверок, скриншоты в `docs/img/phase5-*.png` |

Смоук-тест на Windows тоже требует Chromium: `bunx playwright install chromium` (один раз).

## 3. На что смотреть при тесте

Главный вопрос среза — **хочется ли сделать ещё один найм и ещё одно слияние?** Ответ «да» значит, что ядро работает и можно строить Фазу 6. Ответ «нет» дешевле исправить сейчас.

Играй 5–10 минут на телефоне, лучше дать поиграть и кому-то ещё (ребёнку, другу), не объясняя ничего.

**Первые 10 секунд**
- [ ] Понятно ли без слов, что делать? Сколько секунд до первого тапа, до первого найма, до первого слияния?
- [ ] Видна ли подсказка и не мешает ли она?
- [ ] Смешно ли? Узнаётся ли «Конторка» с первого кадра?

**Ощущения (game feel)**
- [ ] Тап «сочный»: есть отклик глазами (числа, циферки, сплющивание) и ушами?
- [ ] Слияние — главный момент: штамп, тряска и фанфара дают «вау», а не раздражают?
- [ ] Перетаскивание точное: батракан под пальцем, цель подсвечивается, не промахиваешься мимо стола?
- [ ] Не бывает ли, что тап случайно становится перетаскиванием или наоборот?

**Читаемость**
- [ ] Различимы ли ранги с одного взгляда? Нужна ли цифра на столе?
- [ ] Читаются ли всплывающие числа и не превращаются ли в кашу при 8 батраканах?
- [ ] Всё ли помещается на твоём экране, ничего не залезает под вырез камеры и системные панели?

**Темп и экономика** (числа ещё не подогнаны, важны ощущения)
- [ ] Когда становится скучно? Появляется ли «мёртвое ожидание», когда нечего делать?
- [ ] Не слишком ли быстро заполняются 8 столов? Пригодилась ли слоповина?

**Техника**
- [ ] Плавность: нет ли рывков при тапах и слиянии? Если на твоём телефоне заметно подтормаживает — это главный сигнал для решения Canvas2D против PixiJS.
- [ ] Греется ли телефон за 5 минут?
- [ ] Звук: не раздражает ли музыка на 3-й минуте, не слишком ли громкие частые звуки?
- [ ] Сверни браузер и вернись: игра на паузе, звук молчит, прогресс на месте?
- [ ] Закрой вкладку и открой снова: прогресс сохранился?

Напиши, что заметил, свободным текстом — даже «скучно на второй минуте» ценно.

## 4. Измерения

| Метрика | Результат | Цель | Как измерено |

| Время до интерактива, локально | ~0.12 с | — | `bun run smoke` |

## 5. Что нашлось и исправлено при сборке среза

Смоук-тест и скриншоты поймали то, что тесты логики не видят:
- **Головы первого ряда уходили под верхнюю панель.** Раскладка не оставляла места над первым рядом. Теперь масштаб считается с запасом под рост батракана, а юнит-тест раскладки проверяет это на 6 размерах экрана, от 320×568 до 1280×720.
- **Подсказка «Колупай циферки!» была за пределами экрана.** Тест проверял текст, а не видимость — добавлена проверка положения на экране.
- **Гонка подписки UI.** Первый снимок публиковался до того, как Preact подписывался, и на маленьком телефоне HUD показывал «0 / +0/с» до первого кукиша. Исправлено в `useStore`, добавлена проверка в смоук.
- **Кнопка найма пульсирует во время подсказки.** Автотест считал её «нестабильной». Игроку это не мешает, тест нажимает её как палец.

## 6. Отклонения от архитектуры (Фаза 3) и почему

- **Команды — функции** (`hire(state, q)`, `move(state, from, to, q)` и т.д.), а не объекты `Command`. Смысл тот же: единственный способ изменить состояние, правила в одном месте. Но без аллокации объекта на каждое действие и с проще читаемыми тестами.
- **Стейт-машина приложения пока минимальная:** игра и пауза при скрытой вкладке. Полная (`Offline`, `DailyBonus`, `Modal`, `Event`, `Reorg`, `AdPause`) появится вместе с этими экранами в Фазах 6–7.
- **Выплаты дискретные** (раз в секунду со стола), а не непрерывное начисление. Каждая выплата — событие, которое сцена превращает во всплывающее число. Так idle-доход «видно» и приятно, а сумма в секунду та же (закреплено тестом).
